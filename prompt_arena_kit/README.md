# Prompt Arena: student kit

1. In Colab, open `notebooks/R0_setup_check.ipynb` first (before class).
2. Add your API key under the key icon (Secrets): `ANTHROPIC_API_KEY` (or `OPENAI_API_KEY`), notebook access on.

4. No key? Set `PROVIDER = "mock"` to practise with a free fake model (scores will not mean anything).
